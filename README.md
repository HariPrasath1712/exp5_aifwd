# Quiz & Event Countdown

Open `index.html` in a browser to test two widgets:

- Quiz App with Timer: click "Start Quiz" to begin a 10-second quiz. At 5 seconds remaining a warning appears. The quiz auto-submits at zero, disables inputs, and shows the score.
- Event Countdown Timer: pick a future date/time and click "Start Countdown". The display updates every second and shows "Registration Closed" when time is up.

No build steps required — just open the file in any modern browser.
